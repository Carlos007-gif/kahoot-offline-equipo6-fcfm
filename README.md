# kahoot-offline-equipo6-fcfm
Quiz interactivo en tiempo real y offline tipo Kahoot, desarrollado por el Equipo 6 de Metodologías de la Programación de la FCFM-UANL. Usa Flask-SocketIO, WebSockets, Python, HTML, CSS y JS. Incluye 7 preguntas, puntuación automática, temporizador, podio en vivo y panel del presentador. En red local aislada. Autor: Carlos Daniel Martinez Reynoso.
